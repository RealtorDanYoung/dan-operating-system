# Roadmap

## Phase 1 (Current)
- Local FastAPI lead intake and dashboard
- SQLite persistence
- Basic validation and status updates
- Follow-up messaging templates

## Phase 2
- Add filtering (status, source, date)
- Add CSV export endpoint
- Add reminder timestamps for next follow-up date
- Add simple auth for local privacy

## Phase 3
- CRM integration adapter layer (HubSpot/Follow Up Boss style interface)
- Structured email/SMS integration abstraction
- Analytics view (lead source conversion, response time)

## Phase 4
- Multi-user roles
- Mobile-friendly dashboard improvements
- Automated nurture sequences based on status and age
